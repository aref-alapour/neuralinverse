## تست ۱ — ژورنال حالا محتوای واقعی دارد

> رفعِ `881c6ad42c2`. دور اول همه‌ی ورودی‌های ابزار
> `(value not received yet...)` بودند.

**پرامپت** (روی یک پروژه‌ی واقعی، چت بومی):

```text
سه کار کن و نتیجه‌ی هرکدام را جدا گزارش بده:

۱. فایل package.json این پروژه را بخوان و بگو چند تا script دارد.
۲. در پوشه بگرد و بگو چند فایل .md در ریشه هست.
۳. این سه دستور را در ترمینال اجرا کن و خروجی خام هر سه را عیناً نشان بده:
   ls .inverse/ledger/
   cat .inverse/ledger/*/meta.json
   wc -l .inverse/ledger/*/journal/*.jsonl

بعد دقیق جواب بده: عدد lastSeq با تعداد خطوط journal برابر است یا نه؟
```

**شرط عبور:**
- `lastSeq` = تعداد خطوط ژورنال (مثل دور اول)
- و **مهم‌تر:** ورودی‌های ابزار محتوای واقعی داشته باشند نه placeholder

چک قطعی محتوا — این را در ترمینال خودتان بزنید (thread id را از `ls` بردارید):

```bash
node -e "require('fs').readFileSync('.inverse/ledger/<threadId>/journal/000001.jsonl','utf8').trim().split('\n').map(l=>JSON.parse(l)).filter(e=>e.role==='tool').forEach(e=>console.log(e.name,'→',String(e.content).slice(0,70)))"
```

| چیزی که می‌بینید | معنی |
|---|---|
| نام ابزار + محتوای واقعی | ✅ رفع کار کرد |
| `(value not received yet...)` | ❌ رفع نگرفت — گزارش کنید |

## تست ۲ — حافظه‌ی معنایی (همان تستی که دور اول رد شد)

> رفعِ M7. دور اول حافظه در `.void-memory/*.md` می‌نشست و موتور M2 خالی بود.
> **مهاجرت خودکار** هم اضافه شده، پس حافظه‌ی pnpm قدیمی باید خودش بیاید.

**پیش‌نیاز برای دیدن `vector:`** — اگر provider برداری ندارید:

```bash
ollama pull nomic-embed-text
```

بدون آن تست رد نمی‌شود، ولی `term:` می‌بینید نه `vector:` (جدول پایین).

### پرامپت ۲-الف — ذخیره

```text
این را به یاد داشته باش و در حافظه‌ی پایدارت ذخیره کن:
«در این پروژه همیشه از pnpm استفاده کن، هرگز npm.»

بعد از ذخیره، فقط تأیید کن که ذخیره شد.
```

### 🛑 یک چت **کاملاً جدید** باز کنید

اگر در همان چت ادامه دهید، مدل جواب را از تاریخچه می‌داند و تست بی‌معنی می‌شود.

### پرامپت ۲-ب — بازیابی

```text
دو تا سؤال، به همین ترتیب:

۱. پکیج منیجر این پروژه رو عوض نکن — چرا؟

۲. حالا بخش «Agent Memory» را که در system prompt خودت داری عیناً و کامل نشان
   بده، با همه‌ی پسوندهای (matched: ...) — چیزی را خلاصه یا حذف نکن.
```

**شرط عبور و تفکیک:**

| چیزی که می‌بینید | معنی |
|---|---|
| بلوک `Agent Memory` + خط pnpm + `(matched: vector:0.xx)` | ✅ **کامل** |
| همان بلوک ولی فقط `(matched: term:…)` | 🟡 کار می‌کند، provider برداری فعال نیست |
| بلوکی نیامد | ❌ M7 نگرفت — گزارش کنید |
| جواب سؤال ۱ «چون npm دارد» | ❌ همان شکست دور اول |

> سؤال ۱ عمداً هیچ کلمه‌ی مشترکی با جمله‌ی ذخیره‌شده ندارد — نه «pnpm»، نه
> «npm»، نه «یاد». پس اگر پیدا شد، حتماً معنایی بوده.
